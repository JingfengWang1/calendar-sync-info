PERSONAL CALENDAR UTILITY · 个人日历工具

Calendar Sync Personal

将本人选定的 Google Calendar 与 iCloud Calendar 配对，通过 vdirsyncer 在 GitHub Actions 中定期双向同步。

A personal utility for synchronizing an explicitly selected Google Calendar and iCloud Calendar using vdirsyncer on GitHub Actions. It is operated by its account owner and is not a public sign-up service.

应用功能

同步选定日历中的事件新增、修改和删除，并尽可能保留标题、描述、时间、时区、地点、提醒及重复规则。每小时调度可能延迟，不提供实时同步保证。

当前实现仅允许账户所有者明确选择的专用测试日历。双向冲突会停止同步；异常大量删除会触发保护。完成账户授权及测试验收前，持续同步保持关闭。

为什么需要 Google 日历读写权限

Google CalDAV 接口需要 OAuth 日历权限，才能读取事件并将 iCloud 中的新增、修改和删除写回 Google Calendar。该授权范围可覆盖账户的其他日历；本工具通过配置及运行时校验，将实际操作限制在所选的一对日历。

首次授权在账户所有者本机的系统浏览器中完成。此说明网站不提供登录、密码输入或授权回调功能。
